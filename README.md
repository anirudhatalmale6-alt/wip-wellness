# Work in Progress Wellness — website

A plain, fast, hand-built website. No WordPress, no page builder, no plugins,
no monthly platform fee. Just files.

Everything the live site needs is inside the **`site/`** folder.

---

## 1. Putting it live on Hostinger

1. Log in to Hostinger and open **hPanel → Files → File Manager**.
2. Open the folder called **`public_html`**. If there is a placeholder
   `default.php` or `index.html` already in there, delete it.
3. Upload **the contents of the `site/` folder** — not the folder itself.
   When you're done, `public_html` should contain `index.html`, `contact.html`,
   the `assets` folder, and so on, sitting at the top level.
   - Tip: zip the contents first, upload the one zip, then use File Manager's
     "Extract" option. Much faster than dragging 15 files.
4. Visit your domain. That's it — the site is live.

There is nothing to install, no database, and no admin login to remember.

## 2. Changing the words yourself

Every page is a single `.html` file you can open in File Manager and edit
straight in the browser (right-click → Edit).

| Page on the site      | File                        |
|-----------------------|-----------------------------|
| Home                  | `index.html`                |
| Our Team              | `team.html`                 |
| Individual Therapy    | `individual-therapy.html`   |
| Mindfulness Coaching  | `mindfulness-coaching.html` |
| Parenting Guidance    | `parenting-guidance.html`   |
| Retreats              | `retreats.html`             |
| Testimonials          | `testimonials.html`         |
| Contact               | `contact.html`              |

The text sits between tags that look like `<p>` … `</p>` or `<h2>` … `</h2>`.
Change the words, leave the tags alone, save. Refresh the site to see it.

**If you want a page removed** (e.g. Parenting Guidance): delete its file, then
remove its line from the menu near the top of each remaining page — search for
`parenting-guidance.html` and delete that whole `<a ...>` line wherever it appears.

## 3. Swapping a photo

Photos live in `assets/img/`. Replace a file with your own, keep the **same
file name**, and the site picks it up automatically.

| File               | Where it appears                          |
|--------------------|-------------------------------------------|
| `hero-water.jpg`   | Big image at the top of the home page     |
| `grae-rose.jpg`    | Your portrait (home page + Our Team)      |
| `calm-lake.jpg`    | Wide image band, home page and Retreats   |
| `calm-pond.jpg`    | Wide image band at the foot of most pages |

Image credits: `hero-water.jpg` and `grae-rose.jpg` are yours, carried over from
the old site. `calm-lake.jpg` and `calm-pond.jpg` are public-domain photographs
from Wikimedia Commons — free to use commercially, no attribution required, no
stock licence to worry about. Swap them for your own whenever you like.

## 4. The contact form

There is no self-booking calendar anywhere on the site — by design. People are
pointed at phone, text and email so you can speak with them first.

The "Send a message" form on the Contact page currently opens the visitor's own
email app with the message pre-filled and addressed to
`wiprelationshipcounseling@gmail.com`. It works everywhere and costs nothing,
but it does rely on the visitor having an email app set up.

If you'd rather the form delivered straight to your inbox without that step,
that's a small change — say the word.

Note: the form is **not** a HIPAA-secure channel, and the page says so. Keep it
for "please call me back", not clinical detail.

## 5. Search engine bits already done

- Unique page title and description on every page
- Structured data (`ProfessionalService`, address, phone, fees, services) so
  Google can show the practice properly in search and maps
- `sitemap.xml` and `robots.txt`
- Social-sharing preview image and text
- Real headings, image alt text, skip link, keyboard-accessible menu
- Fast: no framework, no jQuery, ~50 KB of code

Once the domain is live, the one job left is to claim the **Google Business
Profile** for the practice and submit `https://yourdomain/sitemap.xml` in
Google Search Console. Happy to walk you through both.

## 6. For a developer (or future me)

- `site/` is the deployable folder. Nothing outside it is needed in production.
- `index.html` is hand-written.
- The other pages are generated by `build/pages.py` so the header, footer and
  navigation stay identical everywhere. After editing that script, run:

  ```
  python3 build/pages.py
  ```

  If you only ever edit the finished HTML by hand, you can ignore the script
  entirely — it will just overwrite your changes if you run it, so don't.
- `site/assets/css/style.css` is the whole design system (colour, type, spacing
  are all CSS custom properties at the top of the file).
- `site/assets/js/main.js` is ~90 lines of vanilla JS: sticky header, mobile
  menu, scroll reveals, form handler.
- Fonts are Newsreader + Karla, loaded from Google Fonts.
